All sources accessed **2026-09-30** unless noted. "Verified" here means the behavior was read in official
documentation. It does **not** mean the integration was exercised against a live service. Live status is
tracked separately in [integration-status.md](integration-status.md).

Permission-change detection needs `Prefer: deltashowremovedasdeleted, deltatraversepermissiongaps, deltashowsharingchanges` **and Sites.FullControl.All**, so the connector instead re-reads permissions per changed item and runs a periodic full reconciliation. | https://learn.microsoft.com/en-us/graph/api/driveitem-delta?view=graph-rest-1.0 |
| Graph item permissions | `GET /drives/{drive-id}/items/{item-id}/permissions` (app: `Files.Read.All`) returns *effective sharing permissions* (direct + `inheritedFrom`).
