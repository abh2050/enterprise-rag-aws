# Amazon S3 connector

**Status:** ingestion and lifecycle behavior recorded live in dev on 2026-10-01; see [verification](../verification/README.md). Full retention/recovery behavior still requires validation. In AWS: S3 → EventBridge → SQS → Step Functions
→ worker. The `list_changes` path is used for reconciliation.

Layout: `s3://<bucket>/<prefix>/<collection>/_access.yaml` is the source permission record for each collection,
using the same schema as `data/private/_access.example.yaml`. Revisions use `VersionId` (bucket versioning is required).
`fetch` pins the exact version it checked. Objects without a valid manifest are denied and quarantined.

Configure: `ERP_S3_SOURCES=["<bucket>/<prefix>"]`, `ERP_S3_GOVERNANCE=manual|purview_datamap`.
